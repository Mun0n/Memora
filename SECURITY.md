# Security and privacy reporting

Memora is pre-alpha and must not be used with real personal or health data.

Do not open a public issue containing credentials, personal data, health data, private photographs or an exploitable vulnerability. Until a private reporting channel is published, prepare a minimal redacted report and contact the repository owner privately. A public security contact will be added before any beta release.

Reports should describe the affected component, reproducible impact and a safe proof of concept using fictional data. Never access or retain data that is not yours.

Production deployment is not supported at this stage. Security review, retention operations, incident response and tested Supabase RLS/storage policies are release gates.
